### 关于对比度偏差（留给项目主人决定）

四个结论标签的白字都低于 4.5:1（但都 ≥3:1，达到「非文本元素/大文本」的标准）。影响：视力不佳的用户在小字号下辨认标签文字会吃力。
三种改法（都不影响功能）：
1. **加深四色底色**，让白字达标 —— 改动最小，但会让整体配色变重；
2. **标签文字改成深色**（如 `#2a2f3c`）压在浅色底上 —— 需要把四色改为浅色调；
3. **维持现状**，接受 3:1 档位 —— 如果更看重配色的清爽感。
本次未做任何改动，等拍板。

- **场合**：第三周验收（周验证日）。先全量复跑，再用独立探针逐条复验上轮（Day 14）记录的卡点。
- **首跑结果**：**ALL_PASS（112 项硬门槛）** + filter-check ALL_PASS(75) + 线上公网检查 19/19 —— 全绿。
  但**全绿不等于没问题**：这次的真 bug 是验收探针（不是门槛）挖出来的。
- **挖出的真 bug**：卡片悬停「上移」在现场**从来没生效过**。
  - 表象：`.card:hover { transform: translateY(-4px) }` 写着，悬停却只有阴影变深、卡片不动。
  - 根因：`.card.pop { animation: popIn .45s both }` 的 `both` 把动画结束后的 `transform:none`
    **长期保留**，而 **CSS 动画优先级压过 `:hover` 普通声明**。
  - 确证（四步实测）：带 `.pop` 悬停 Y=0（`popIn:finished`）→ 摘掉 `.pop` 悬停 Y=−4px。
  - 修法：填充模式 `both` → `backwards`（入场期间的起始态照旧，动画结束后释放 transform）。
- **为什么 112 项没拦住 —— 这条最值得记**：`B1_卡片hover有反馈` 查的是 `transform !== 'none'`，
  而动画留下的**单位矩阵 `matrix(1,0,0,1,0,0)` 也不是 `'none'`**。
  **断言确实在跑，但它断的是一个不成立的充分条件 —— 弱断言式的假绿。**
  → **判「有效果」不能只看样式存在 / 属性非空，要测出那个效果本身。**
- **加固**：
  - `B1_卡片hover有反馈`：改成**实测 Y 位移真的变小**（先把鼠标移开再取基准，避免上一段交互的悬停残留污染基准）。
  - 新增 `B1b_入场动画不长期占用transform`：源码层堵根因（`.card.pop` 的填充不许是 `both`/`forwards`）。
  - 硬门槛 112 → **113**。
- **反向验证（必做）**：故意把 `both` 塞回 CSS 重跑 → `B1` 与 `B1b` **双双变红**、位移 `0 → 0`；
  还原后重跑 → `0 → -4`、ALL_PASS(113)。**断言不是摆设，是真的会拦住。**
- **顺带的两条**：① 线上榜单 9 → 7 条是周榜随日期自然收窄、论坛「6 已通过」→「7 已通过」是上次后台过审所致，
  **都是数据变化不是回归**，写记录时要说清，免得下次误判；② 复验里我第一次把探针写错了
  （`#header-avatar` 其实是 `<span>`，链接在外层 `a#header-me`；`#mode-trace` 是 hidden 容器，切换要点
  `#search-modes` 里的按钮）—— **探针报红先怀疑探针**，别急着当产品 bug 报出去。
