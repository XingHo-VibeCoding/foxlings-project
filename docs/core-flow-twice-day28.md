## 三条必须说清楚的口径（不然这条记录会被误读）

1. **这一遍走的是「未登录用户」路径**。未登录时线索只存本机 localStorage（界面自己写明「仅本机」），所以这里的「写入/持久化」证明的是**用户侧闭环**，不是云端写库。
2. **云端写入 + 刷新持久化由另一条探针单独证明**：`verify/probe-day28-write-persist.js` —— `rpc bump_item_view` 把 `views` 从 2 写到 3，隔 1.2 秒再读仍是 3；独立验收官又自写探针复现了 3→4 / 5→6 / 7→8 三次（见 `docs/day28-auditor-report.md` 抽验 A）。两条路径合起来才覆盖「线上持久化」。
3. **「修改」不是没测、是产品没做**：`js/mine.js` 里线索列表只渲染「删除」一个按钮；登录前删的是本机留底，登录后客户端既不给改也不给删（防篡改口径）。所以这一步**两遍都是「未提供」，不是「测失败」**。
